# Off-Season Strength

> Hold the engine, keep the joints honest, and let strength lead.

- **Tue — upper (pull biased)**, **Wed — legs**, **Fri — upper (push biased)**:
  the strength days, each opened by prehab.
- **Mon — bike + athleticism**: fast feet, explosiveness, core.
- **Thu — bike**, then optional lower conditioning.
- **Saturday** — R&R.
- **Sunday** — a short run; strides if the legs feel good.

## Monday — Bike + athleticism  <!-- M Bike + Athleticism -->

Bike, then athleticism — fast feet, explosiveness, core. Quality over
volume: low contacts, land quick, stop before anything gets grindy.

| Block | Exercise | Sets | Reps | Rest | Notes |
|---|---|---|---|---|---|
| Ride | Bike | 1 | 15 min |  | easy–moderate, Z2 |
| Warm-up | Ankle Work | 2 |  |  | weighted SL pogos, patterned hops |
| | Open knee drives | 2 | 10–15 |  | groin |
| | SL KB leg raise | 2 | 10–15 |  | hip flexors |
| CNS primers | Sprinter iso hold | 3 | 3–5s |  |  |
| Fast feet | Box quick feet | 3 | 10–15s | :45 | as fast as possible, stay light |
| | Hurdle quick feet in & out | 2 | 3 each way | :45 |  |
| Explosive | Broad jumps | 3 | 5 | :90 | low contacts, not grindy — land quick; every few weeks swap for SL bounds for distance |
| | Depth drop + quick hop | 2 | 6 | :90 | land and rebound instantly — train fast amortization |
| | Gwiz jumps | 2 | 5 | :90 |  |
| Core | Pallof hold + march | 2 | 10–15s/side | :45 |  |
| | GHD situps | 3 | 10–15 | :60 |  |
