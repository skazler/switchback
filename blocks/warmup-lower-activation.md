# Lower Activation Warmup

2 × 10–15 each, before sprints / athleticism / long zone 2.

| Exercise | Target |
|---|---|
| Open knee drives | groin |
| SL KB leg raise | hip flexors |
| Copenhagen planks (or drop catches) | adductor & groin |
| SL hip thrust (or glute bridge switches) | glutes & hamstrings |
| Foot resisted TKEs | knees |
| Hamstring decel work | hamstrings |
| SL seated tib raises | tibialis anterior |
| Banded wall sprints | full activation |
